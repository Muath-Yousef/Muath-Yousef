# Mu'ath Yousef

Cybersecurity Engineer focused on practical SOC engineering, security automation, and evidence-driven security operations.

I am building **SOCRoot**, an evolving security engineering initiative that grew from **Project Synapse**. The work explores how SIEM, SOAR, case management, evidence capture, observability, and AI-assisted analysis can be combined into safer and more accessible security operations.

## Current focus

- SOC, SIEM, and SOAR engineering
- Detection and incident-response workflows
- Human-in-the-loop security automation
- Evidence capture and audit-friendly reporting
- Security architecture for small and medium-sized organizations
- Safe integration of AI into security operations

## Engineering principles

- Sensitive remediation stays human-controlled
- SOAR dry-run is the default
- CDN and RFC1918 ranges are never automatically blocked
- DNS events remain notification-only
- Raw client data is not sent to external AI providers
- Production claims require documented tests, rollback paths, and operational evidence
